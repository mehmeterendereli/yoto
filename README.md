# Yoto

> **Archived historical project. This repository is not maintained or supported.**

Yoto was a Python desktop prototype for assembling narrated videos from generated text, stock-media search results, speech synthesis, and FFmpeg processing.

## Archive status

- The last source update predates this archive review and the third-party API integrations were not revalidated.
- No current output-quality, reliability, platform-compatibility, or service-availability claim is made.
- The repository contains no automated tests or release artifacts.
- Do not provide production API credentials before independently reviewing the dependencies, network calls, and data-handling code.

The code remains available for historical inspection. There is no designated maintained successor; current public work is listed in the [open-source portfolio](https://www.mehmeterendereli.com/en/open-source).
